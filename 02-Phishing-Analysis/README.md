
# Project 2: Phishing Email Analysis

## Project Overview
This project demonstrates the process of investigating a suspicious email to identify potential phishing indicators and assess security risks.

## Objectives
- Examine a simulated suspicious email.
- Identify potential phishing indicators.
- Analyze the sender, subject line, links, and message content.
- Determine the potential security risks.
- Recommend appropriate security response actions.

## Tools and Skills
- Email security analysis
- Phishing detection
- Threat identification
- Incident documentation
- Security awareness
