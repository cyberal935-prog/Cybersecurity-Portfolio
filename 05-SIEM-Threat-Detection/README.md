
# Project 5: SIEM Threat Detection and Security Monitoring

## Project Overview

This project demonstrates foundational Security Operations Center (SOC) skills through hands-on security log analysis using a SIEM platform.

The investigation focuses on identifying suspicious authentication activity, analyzing potential security threats, and documenting findings.

## Project Objectives

- Understand SIEM fundamentals.
- Import and search sample security logs.
- Identify suspicious authentication patterns.
- Investigate potential brute-force login attempts.
- Evaluate security alerts.
- Document findings and recommended actions.
