# Log Analysis Fundamentals — TryHackMe

## Project Overview
This project documents my learning from the TryHackMe Intro to Log Analysis room. I explored how security analysts use system and web server logs to investigate activity, identify unusual patterns, and support incident investigations.

## Skills Covered
- Linux command-line fundamentals
- Web server log analysis
- Searching and filtering log entries
- Identifying HTTP response codes
- Extracting IP addresses and URLs

## Commands Studied
- `cat` — Display file contents
- `less` — Navigate large log files
- `tail` — View recent log entries
- `wc` — Count lines, words, and characters
- `cut` — Extract fields from logs
- `sort` — Sort log entries
- `uniq` — Identify repeated entries
- `grep` — Search for specific patterns
- `awk` — Filter and process structured text
- `sed` — Transform text
